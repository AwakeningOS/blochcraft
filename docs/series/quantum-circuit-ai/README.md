# 量子回路プログラミング講座

BlochCraftを使い、量子回路の動きを可視化しながら、その本質を理解するための連載制作フォルダーです。

## このフォルダーの読み方

1. `SERIES_CHARTER.md` — 連載の目的と、絶対に外してはいけない思想
2. `SERIES_STATE.md` — 現在どの記事を、どこまで書いているか
3. `ARTICLE_MAP.md` — 連載全体の予定
4. `EDITORIAL_GUIDE.md` — 文体、説明方法、避ける表現
5. `articles/` — 各回の原稿

新しいエージェントは、会話履歴を推測する前に上記の順番で読んでください。
