# 【第1回】BlochCraftで0を1にし、50%の状態を作ってみよう

量子回路の図には、XやHと書かれたマスが並びます。それだけを見ても、量子ビットの中で何が起き、最後の0や1にどう結びつくのかはなかなか分かりません。

BlochCraftでは、回路に置いたゲートの働きを球体の動きで確かめ、その結果を0と1の可能性として読めます。まずは0を1へ反転するXから始め、画面の表示がどうつながっているかを実際に動かしながら確かめていきます。

[**BlochCraftを開く**](https://awakeningos.github.io/blochcraft/) **（インストール不要・ブラウザーで開きます）**

![](https://assets.st-note.com/img/1783941155-7LrMzxd8iXTHa2Sqc6YOj4Zy.png)

  

---

## 何も置いていない回路を確認する

「3量子ビット回路エディター」まで移動してください。

![](https://assets.st-note.com/img/1783941506-XdiRIKOvjDQ32A0utyklLm9o.png)

  

A・B・Cと書かれた3本の横線が、これから操作する3個の量子ビットです。上に並ぶ1、2、3は操作を置く列の番号で、回路は左から右へ順番に実行されます。

BlochCraftでは、新しい回路を開くとA・B・Cのすべてが0の状態から始まります。回路のマスが空なのは、この初期状態にまだ何の操作も加えていないからです。

回路の下にある「可能性の表」は、現在の状態でA・B・Cを測定した場合に、どの結果がどれくらいの確率で得られるかを示しています。

1個の量子ビットを測定した結果は0か1です。量子ビットが3個あるため、結果の組み合わせは次の8通りになります。

000 001 010 011  
100 101 110 111

3桁の数字は、左からA・B・Cの順に読みます。たとえば 100 は「Aが1、Bが0、Cが0」という結果です。

各行の青いバーと右側の百分率は、その結果が得られる確率を表します。その下の「振幅」は確率のもとになる値です。振幅の大きさを2乗すると、その行の確率になります。振幅についてはHを操作するときに、実際の変化を見ながら詳しく確認します。

現在はまだ何も操作していないため、A・B・Cは必ずすべて0として測定されます。そのため、000 だけが100%で、それ以外の7通りはすべて0%です。

右側の「単体状態」にも、A・B・Cはそれぞれ「北 |0⟩ 100%」と表示されています。BlochCraftの球体では、北が0、南が1を表します。可能性の表と単体状態は、どちらも「3個とも0から始まっている」という同じ初期状態を別の方法で示しています。

---

## AにXゲートを置く

部品一覧から X を選び、Aの1列目をクリックしてください。

Xは、量子ビットの0と1を反転させるゲートです。

> 0 → 1  
> 1 → 0

  

今回は初期状態が0なので、Xを通ったAは1になります。Aの1列目に置くのは、「回路の最初の操作として、AにXを作用させる」という意味です。

```
1      2      3 
A: ──X──  ─────  ─────
B: ─────  ─────  ─────
C: ─────  ─────  ─────
```

可能性の表を見ると、操作前に100%だった 000 は0%になり、代わって 100 が100%になっています。

![](https://assets.st-note.com/img/1783942050-tmK5B2MR3yZPD7IXnbEwVsOz.png)

  

100 は、左から順に「Aが1、Bが0、Cが0」という結果です。Xを置いたAだけが1へ変わり、何も置いていないBとCは0のまま残っています。

右側の「単体状態」でも、Aは「北 |0⟩ 0% / 南 |1⟩ 100%」へ変わり、BとCは「北 |0⟩ 100%」のままです。

回路上のX、可能性の表の 100、単体状態の「Aは南100%」は、すべて同じ変化を表しています。  
  

---

## XでAがどう動いたのか、球体で確かめる

可能性の表から、XによってAが0から1へ変わったことは確認できました。次は、その変化が球体上でどのような動きとして表されるのかを見てみましょう。

回路に置いたX、または1列目の番号をクリックします。選択した列が紫色の枠で囲まれ、ページ上部の「全操作・球体ビューワー」が1列目のXと連動します。

ページ上部へ戻ると、「操作の進み」は100%になっています。これは、Xの回転が完了した後の状態を表示しているという意味です。

球体を見ると、白い矢印は北 |0⟩ ではなく、南 |1⟩ を向いています。可能性の表に表示された「Aは1」という結果が、球体では「矢印が南を向く」という形で表されています。

![](https://assets.st-note.com/img/1783942245-pNzUOo7Xfxh5KCFnEYHZBqWe.png)

  

球体の下には、Xの動きが数値でも表示されます。

-   回転軸：東西軸  
    Xは、球体を東と西を結ぶ軸の周りに回転させます。
    
-   回転量：180°  
    半回転するため、北にあった矢印は反対側の南へ移ります。
    
-   現在位置：Z = -1  
    南北方向の座標が最も南にあることを示します。北 |0⟩ は Z = 1、南 |1⟩ は Z = -1 です。
    

完成後の状態だけでなく、移動する途中も確認できます。「操作の進み」を0%まで戻してから、ゆっくり100%へ動かしてください。

0%では白い矢印が北 |0⟩ にあり、スライダーを進めるにつれて東西軸の周りを回ります。100%に達すると、矢印は南 |1⟩ に到着します。

「操作の進み」は、回路の内容や計算結果を変更するものではありません。選択したゲートが量子状態をどの経路で動かすのかを、途中で止めながら観察するためのスライダーです。

## Xを2個並べ、回路の途中を前後する

1個目のXによって、Aが0から1へ変わることを確認しました。では、1になったAへ、もう一度Xを作用させるとどうなるでしょうか。

Xを選んだ状態で、Aの2列目をクリックしてください。

```
1       2       3
A:   ──X──   ──X──   ─────
B:   ─────   ─────   ─────
C:   ─────   ─────   ─────
```

回路は左から右へ進むため、Aは1列目のXを通った後、2列目のXを通ります。

Xは0と1を反転させるゲートです。1個目のXで0から1へ変わり、2個目のXでもう一度反転して0へ戻ります。

回路の下にある「状態を見る位置」を「2列目の後」に合わせてください。

![](https://assets.st-note.com/img/1783942552-WkUiCK4ynaOXflHDc8grGxhp.png)

  

可能性の表では、000 が100%になっています。A・B・Cの単体状態も、すべて「北 |0⟩ 100%」に戻っています。

### 1列目の後を見る

「状態を見る位置」を「1列目の後」へ動かしてください。

回路上のXは2個とも残っていますが、可能性の表は 100 が100%に変わります。単体状態では、Aだけが「南 |1⟩ 100%」になります。

![](https://assets.st-note.com/img/1783943328-cKDpNIAvdjXJeslCG45VRhwr.png)

  

これは2列目のXを削除した状態ではありません。完成した回路はそのままにして、1列目を通過した直後の状態だけを表示しています。

### 2列目の後を見る

今度は「状態を見る位置」を「2列目の後」へ動かします。

薄紫の選択カーソルが2列目まで進み、可能性の表は再び 000 が100%になります。Aの球体の矢印も南 |1⟩ から北 |0⟩ へ戻ります。

![](https://assets.st-note.com/img/1783943386-G4CvMryKma7ZjEiVh5AqgfHk.png)

  

このように「状態を見る位置」は、完成した回路の内容を変えずに、各列を通過した直後の状態を確認するためのスライダーです。

## Hは、斜めの軸に沿って状態を180°回転させる

全部消すボタンを押してから、Hを選び、Aの1列目へ置きます。配置したHをクリックして、上の球体ビューワーを見てください。

![](https://assets.st-note.com/img/1783944739-rpgCV8FLPEmM4D3AiKkHJ6Ue.png)

  

球体には、中心を斜めに貫く紫色の線が表示されています。これがHの回転軸です。Hは、この北東斜め軸を中心に、白い矢印を180°回転させます。

操作前の白い矢印は、北 |0⟩ を向いています。

「操作の進み」を0%から100%へ動かすと、白い矢印は紫色の回転軸の周りを半回転し、最後に東 |+⟩ へ到着します。

球体の下にも、同じ内容が表示されます。

-   回転軸：北東斜め軸
    
-   回転量：180°
    
-   現在位置：X = 1、Y = 0、Z = 0
    

Hの基本的な働きは、この回転です。

可能性の表が50%ずつになるのは、Hが確率を直接半分にしたからではありません。Hによって白い矢印が東へ移動した結果です。

BlochCraftの可能性の表は、現在の状態を北と南の方向から測った場合の結果を表示しています。東を向いた矢印は北と南のどちらにも偏っていないため、Aを測定すると0と1が50%ずつ得られます。

![](https://assets.st-note.com/img/1783945295-eJzpViDT1U9BhLSqr3nRHk7w.png)

  

つまり、理解する順序は次のとおりです。

> Hを作用させる  
> ↓  
> 北東斜め軸の周りに180°回転する  
> ↓  
> 白い矢印が北から東へ移る  
> ↓  
> 北と南の方向から測ると50%ずつになる

  

## 同じHをもう一度作用させる

Aの2列目にもHを置きます。

```
1       2       3  
A:   ──H──   ──H──   ─────
B:   ─────   ─────   ───── 
C:   ─────   ─────   ─────
```

1列目のHを通った後、白い矢印は東 |+⟩ を向いています。

2列目のHも、1個目と同じ北東斜め軸を中心に、白い矢印を180°回転させます。今度は東から回転を始め、北 |0⟩ へ到着します。

> 北 |0⟩  
> ↓ 1個目のH：北東斜め軸の周りに180°回転  
> 東 |+⟩  
> ↓ 2個目のH：同じ軸の周りに180°回転  
> 北 |0⟩

  

そのため、2列目の後では可能性の表も 000 が100%へ戻ります。

Hは「0と1を半々にする操作」ではありません。同じ軸を中心に状態を180°回転させる操作です。最初の状態が北なら東へ移り、東から同じ回転をもう一度行えば北へ戻ります。

この球体上の動きを先に理解すれば、Hを2個並べたときに0へ戻ることも、特別な例外ではなく、同じ回転を2回続けた結果として読めます。

---

## Hの50%を実際に測る

2列目のHを削除してから、Hを1個置いた状態にして、「測定ラボ」へ移動します。A・B・Cのフィルターが `Z |0⟩` であることを確認し、「1000回測定」を押します。

白い矢印は現在の状態、朱色の矢印は測定で0とする方向です。

![](https://assets.st-note.com/img/1783945673-0JaM1nZOv5XEjlPqHFzNUBW2.png)

  

「正確な可能性」は `000` と `100` が50%ずつです。「測定結果」は、たとえば502回と498回のように約半分ずつになります。

-   正確な可能性：現在の状態から計算した理論値
    
-   測定結果：今回1000回試して得られた回数
    

理論値が50%でも、必ず500回ずつになるわけではありません。一回ごとの結果はランダムなので、実測回数は少し揺れます。

## BlochCraftで作った回路を、実行できるコードへ変換する

ここまで使ってきたBlochCraftは、量子回路の動きを学ぶためのアプリです。球体や可能性の表を見ながら、ゲートが量子状態をどう変えるか確認できます。

一方、量子回路をコンピューター上のシミュレーターや実際の量子コンピューターで動かすには、回路の内容をプログラムとして記述する必要があります。

そのために使われるソフトウェアの一つが Qiskit（キスキット） です。

Qiskitは、Pythonというプログラミング言語から量子回路を作成し、シミュレーターや対応する量子コンピューターで実行するための道具です。

BlochCraftとQiskitでは、同じ量子回路を異なる形で表します。

-   BlochCraft：マスにゲートを置いて回路を作る
    
-   Qiskit ：Pythonのコードで回路を書く
    

BlochCraftの一番下にある「回路からQiskitコードへ」には、画面で作った回路をQiskitで書いたコードが表示されています。

BlochCraftの回路は左から右へ進みます。Qiskitのコードは上から下へ実行されます。

BlochCraftで作った回路は、学習画面の中だけで終わるものではありません。Qiskitコードへ変換すれば、同じ回路をシミュレーターで実行したり、測定を繰り返したり、対応する量子コンピューターへ送ったりできます。

球体で動きを理解し、回路として並べ、最後に実行可能なコードへつなぐ。その入口が「回路からQiskitコードへ」です。
