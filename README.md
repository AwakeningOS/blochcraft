# BlochCraft

球体を動かして量子ゲートを理解し、回路記号とコードへ接続する量子回路教育アプリです。

## 現在の段階

`v0.4` は、球体操作・3量子ビット回路エディター・関係金庫ビュー・
測定ラボ・Qiskitコード生成を一つの画面に統合した版です。

- 球体名 / 一般的なゲート名の併記
- 3D風ブロッホ球と6方向（北・南・東・西・表・裏）
- 回転軸、1周軌道、操作済み区間、状態矢印の可視化
- RY / X / Z / H / CNOT / Toffoli
- 条件付きゲートの条件説明
- マウスドラッグ / タッチドラッグによる自由視点
- 3量子ビット×8列の回路エディター
- 回路を任意の列まで実行するステップ表示
- 状態ベクトルから得られる8通りの可能性分布
- 回路途中状態と単体状態の表示
- 回路列から球体ビューワーへの操作同期
- A・B・Cの単体矢印と「各量子ビット対残り全体」の関係金庫表示
- A・B・Cごとに測定方向を選べるフィルター表示
- 正確な測定分布と1回／1000回のサンプル比較
- 回路ステップと測定方向に同期したPython / Qiskitコード生成
- 「何を起こしたい？」から始める別ウィンドウのQuestプロトタイプ
- QuestとLabのリアルタイム回路連携と目的達成判定

## 起動

ブラウザーで `index.html` を開くか、簡易HTTPサーバーを起動します。

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

自由実験画面の最下部にある目的別学習経路、または
`http://localhost:8000/quest.html` からQuestを開けます。現在は「離れた二つの球に
同じ秘密の合図を持たせる」などの目的を試せます。Quest画面は共通で、
選んだ目的に合わせて内容・条件・ヒントが切り替わります。

## テスト

Node.jsの標準テストランナーで、球体数学・回路シミュレーション・
関係指標・測定・コード生成を検証できます。

```bash
node --test tests/*.test.mjs
```

## 設計方針

表示は常に次の3層を接続します。

1. 球体上の意味
2. 世界標準のゲート名
3. Python / Qiskitのコード表現

既存の単体HTMLは動く仕様書として保持し、BlochCraft側では機能をモジュールへ分離して発展させます。
